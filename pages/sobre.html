Sobre o projeto

Rebbity: um projeto que continua evoluindo.

O Rebbity começou como uma plataforma de parceiros para delivery, com cadastro de restaurantes, mercados e gerenciamento de cardápios.

O que está disponível nesta demonstração

A interface pública e o cardápio demonstrativo funcionam no GitHub Pages. Você pode criar, buscar, editar e excluir produtos, testar cardápios separados para restaurantes e mercados, importar e exportar JSON e desfazer alterações localmente.

O que ainda precisa de servidor

Autenticação, cadastros reais de empresas, aprovação de parceiros, armazenamento compartilhado e integrações comerciais dependem de um backend PHP e banco MySQL. Essas funções não são executadas nem simuladas como serviço real nesta página.

Privacidade do modo demonstração

As informações de exemplo ficam no armazenamento local deste navegador. Não informe CPF, CNPJ, senha, dados bancários nem informações de clientes. Você pode limpar os dados a qualquer momento no painel.

Código e desenvolvimento

Consulte o repositório no GitHub e acompanhe a modernização em andamento. A publicação pública não representa homologação de produção.
